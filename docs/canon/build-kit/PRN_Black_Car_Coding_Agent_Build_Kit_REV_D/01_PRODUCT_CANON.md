# Product Canon — Revision D

## Black Car
One problem: homeowner has a house problem and does not know what information matters or what to do next.
One transformation: plain-language/photo/voice evidence -> adaptive clarifiers -> canonical ProblemRecord -> Job-Ready Packet.

## Live continuations
- I already have someone.
- Ask My People.
- Find someone for me: ONE evidence-based provider, Show Another once at a time.

## Live durable layers
Customer Lite, Trust V1, provider entity resolution, provider recommendation lite, page factory, Feature Lab, admin/control plane, consent/rights/provenance, API/MCP safe rails, A36/A25 minimal foundations.

## Deferred runtimes
DIY, SmartQuote, Provider Tracking, provider accounts/dispatch/status, scheduling, quote acceptance, payments, Tool Cloud, Big Company Pricing, full Property Dashboard, Digital Foreman, customer outcome follow-up. OutcomeRecord is schema-only.

## Core rules
- Start with what happened.
- Customer is eyes/hands, not diagnostician.
- Raw evidence != facts != inference != public-safe insight.
- Public SEO data is separately derived, never raw intake.
- Trust answer is evidence, not a PRN endorsement.
- One clear next step; no directory UX.
- Complexity behind the screen.
- Trial smallness = delayed feature layers, not weak infrastructure.
